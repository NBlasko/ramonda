A new project has an `AGENTS.md` for a coding agent: the one command that proves a change (`npm run check`, described from the same list the script is built from), how to look up a diagnostic code, and the rules a habit from other libraries breaks first. It names only what the project has. A one-line `CLAUDE.md` points at it. A folder that already has either file keeps it, and the project's is written beside it, as with `README.md`.
