`--json` on `ramonda-check`, `ramonda-check-bundle` and `ramonda-css` (the check, `lint` and `format --check`): the findings as one JSON object on stdout, in one shape for all three — the rule, the file, the line, the column, the message the text run prints, and what the finding records — with the same exit code. For a program, a coding agent above all, that would otherwise parse the prose. A new project's `AGENTS.md` says so.
