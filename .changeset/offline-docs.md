`ramonda-check explain <code|rule>` and `ramonda-check docs [page]`: the docs for the installed version, offline. `@ramonda/check` now carries the docs as text, packed at release, so `explain RMD020` prints that code's page and `explain unknown-hook-option` that rule's, and `docs forms/fields` any page — with the closest match named for a slip. A new project's `AGENTS.md` sends an agent to them first.
